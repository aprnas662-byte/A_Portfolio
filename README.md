# Aprna Kumari | Premium Developer Portfolio

A high-performance, deeply animated, and bespoke interactive developer portfolio built to showcase full-stack engineering and Python backend architecture. Designed with a focus on fluid motion, minimalist aesthetics, and buttery-smooth user experiences.

![Portfolio Preview](https://via.placeholder.com/1200x630/050505/ffffff?text=Aprna+Kumari+-+Portfolio)

## ✨ Core Features

*   **Fluid Typography & Hero Reveal:** High-end, staggered entry animations for text and headers.
*   **Infinite Skills Marquee:** A continuous, smooth sliding window (marquee) showcasing the technical stack.
*   **Immersive Project Exhibition:** Expansive project cards featuring parallax scroll effects and magnetic hover states.
*   **Interactive Timeline:** A physics-based, scroll-linked timeline for education and certifications.
*   **Inertial Smooth Scrolling:** Integrated Lenis scroll for a heavy, elegant, and frictionless browsing experience.
*   **Bespoke Styling:** Built entirely with Chakra UI for structural and thematic consistency—strictly zero generic templates or Tailwind UI.

## 🛠 Tech Stack

**Core Framework & Languages:**
*   [React 18](https://react.dev/) (via [Vite](https://vitejs.dev/))
*   [TypeScript](https://www.typescriptlang.org/)

**Styling & UI:**
*   [Chakra UI](https://chakra-ui.com/) (Component styling and theme tokens)
*   [Lucide React](https://lucide.dev/) (Minimalist iconography)

**Animation & Motion:**
*   [Framer Motion](https://www.framer.com/motion/) (Complex orchestration, scroll reveals, and magnetic physics)
*   [@studio-freight/lenis](https://github.com/studio-freight/lenis) (Smooth scroll engine)

## 🚀 Quick Start (Local Development)

To run this portfolio locally, ensure you have Node.js installed, then execute the following commands:

```bash
# Clone the repository
git clone [https://github.com/aprnas662-byte/portfolio.git](https://github.com/aprnas662-byte/portfolio.git)

# Navigate into the directory
cd portfolio

# Install dependencies (using npm, yarn, or pnpm)
npm install

# Start the Vite development server
npm run dev
